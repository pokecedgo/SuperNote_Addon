# SuperNote(Ced++)

SuperNote digital notebook personal software that uses AI integration for better note taking.

## Features

- **Live AI comments** – Mirror your Supernote, hit Record, and get short tips and mistake checks beside your writing.
- **Ask about any area** – Circle anything on the page and ask Ced++ about it.
- **Notebooks + Neat Copy** – Store finished pages in folders, each with a cleanly rewritten neat copy.
- **Study tools & search** – Summaries, exam takeaways, and search across every notebook.
- **Lecture audio side notes** – Transcribes the lecture and flags exam dates, deadlines, and "by the way" moments.
